# aoccqa-analysis-report（HTML 呈現層）

- **版本**：1.0.0
- **Phase / 產線位置**：Phase A｜呈現層
- **狀態**：功能已併入 `aoccqa-fsd-parser`（v1.2.0）；獨立使用場景有限

## 定義

把測試需求分析結論**渲染**成「給 PM/Planner 看的六段 HTML 報告」。只負責「呈現格式」，不負責深度解析、來源判讀、缺口/矛盾偵測（那屬 `aoccqa-fsd-parser`）。

## 用途

當已有分析結論、只需把它排版成標準六段 HTML 報告時使用。

## 輸入

- 若已裝 `aoccqa-fsd-parser`：用它的分析結論（需求清單、缺口、矛盾、釐清問題、QA 驗證範圍分類、Source Manifest）。
- 若尚無現成分析：先取得必要素材再渲染，**不為填版面而捏造內容**。

## 輸出

單一自包含 HTML，固定六段（順序固定）：測試目的 / 測試目標 / 測試範圍 / 測試規劃 / 待釐清 / 邏輯不對之處（永遠最後）。讀 `references/report-template.html` 取骨架後替換內容。

### Header 規範

- 標題固定＝來源文件標題（`<title>` 與 H1 一致）。
- 標題下只放一行：`產生時間 ｜ 文件版號`，不放對象或其他說明。
- 版號取來源自身版本/最後更新時間；取不到標「版本：來源未提供」，不捏造。

## 觸發詞

「輸出 HTML 報告」「產出測試需求分析報告」「把待釐清/邏輯不對之處整理成給 PM 看的文件」。

## 使用情境

- 已有分析結論，只想要一份格式一致的六段 HTML 報告交給 PM。
- 註：一般情況直接用 `aoccqa-fsd-parser` 即可（已內含 HTML 產出）。
